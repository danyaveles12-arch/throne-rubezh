# Тронный рубеж (Rust, Bevy 0.14)

Мини-MOBA в 3D: одна линия, две базы. Разрушьте обе башни врага и его трон.

## Запуск

1. Установите Rust: https://rustup.rs
2. В папке проекта выполните:

       cargo run --release

   Первая сборка Bevy занимает несколько минут, потом запуск быстрый.

Linux: понадобятся системные библиотеки (Debian/Ubuntu):

    sudo apt install g++ pkg-config libx11-dev libasound2-dev libudev-dev libxkbcommon-x11-0 libwayland-dev libxkbcommon-dev

Windows и macOS: ничего дополнительного не нужно.

## Управление

- ПКМ: идти или атаковать цель (можно зажать)
- ЛКМ: бросить выбранную способность, атаковать цель или идти
- Q W E R: способности (сначала клавиша, затем ЛКМ в точку)
- Колесо мыши: приблизить и отдалить камеру
- Курсор у края окна: двигать камеру. Пробел возвращает камеру на героя
- 1-4: купить усиление. S: стоп. P: пауза. Esc: отмена прицела. Enter: начать бой

## Устройство

- `src/sim.rs`: вся игровая логика без зависимостей (юниты, способности, крипы, башни, ИИ врага).
- `src/main.rs`: Bevy: сцена, модели из примитивов, камера, мышь, интерфейс.
- `assets/fonts/DejaVuSans.ttf`: шрифт с кириллицей (лицензия рядом).

Если сборка остановилась на ошибке в `main.rs`, скорее всего дело в версии Bevy. Проект написан под 0.14.x.

## Установщик для Windows (одна кнопка)

GitHub соберёт установщик сам, Rust ставить не нужно.

1. Создайте на github.com пустой репозиторий (ветка main) и загрузите в него все файлы проекта, включая скрытую папку `.github`.
2. Откройте вкладку Actions и дождитесь зелёной галочки (10-15 минут).
3. Откройте раздел Releases справа на главной странице репозитория и скачайте `Throne-Rubezh-Setup.exe`.
   Постоянная ссылка: `https://github.com/ВАШ_ЛОГИН/ИМЯ_РЕПОЗИТОРИЯ/releases/latest/download/Throne-Rubezh-Setup.exe`
4. Запустите установщик. Он ставит игру в папку пользователя, права администратора не нужны, и создаёт ярлык на рабочем столе.

Windows может показать предупреждение SmartScreen, потому что установщик не подписан. Нажмите «Подробнее», затем «Выполнить в любом случае».
